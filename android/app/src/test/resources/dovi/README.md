RPU-only vectors (no movie pictures), MIT licensed quietvoid/dovi_tool,
source commit 41dae646193c12de152333ff5dbc33579cb9ef4a (`assets/tests`).
`mel_orig.bin`, `fel_orig.bin`, and `mel_to_81.bin` are copied verbatim.
`fel_to_81.bin` is independently generated by dovi_tool 2.3.4:

    dovi_tool editor -i fel_orig.bin -j mode2.json -o fel_to_81.bin

where `mode2.json` is `{"mode":2}`. The upstream file with that name goes
FEL -> MEL -> 8.1 and intentionally retains FEL mapping; our reference uses
FEL -> 8.1 directly, removing residual-dependent reshaping.
These binary RPU files contain start code + escaped RPU, without HEVC's 7C01
NAL header. The tests add that header to model the on-disc enhancement PID.
